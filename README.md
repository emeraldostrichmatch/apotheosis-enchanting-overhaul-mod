# Apotheosis — Enchanting Overhaul Mod

[![Download Latest](https://img.shields.io/github/v/release/emeraldostrichmatch/apotheosis-enchanting-overhaul-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/emeraldostrichmatch/apotheosis-enchanting-overhaul-mod/releases/latest)

Dramatically expands the enchanting system with new enchantments, gems, and a reforging table.

![Apotheosis — Enchanting Overhaul Mod Preview](https://cdn.modrinth.com/data/rqFWfVlz/images/db664026366182372928c5e24d366d79998a6366_350.webp)

## Features

- 100+ new enchantments beyond vanilla
- Gem Socketing system for item stat bonuses
- Reforging Table to re-roll item enchantments
- Spawner modifiers to fully customise mob spawners
- Village buildings with unique NPC trades

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
